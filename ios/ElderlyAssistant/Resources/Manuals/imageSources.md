# Image sources for bundled instruction manuals

33 files total.


Every image referenced by `manifest.json` resolves to one of the files below.
Images are downloaded into a shared folder next to this file; a manifest path
such as `iphone/step-01.png` refers to `images/iphone/step-01.png`.
All URLs were HTTP-verified (200) at authoring time; the image-fetcher tooling
should treat a failed download as a signal to re-check the source page.

Some files share one source URL (the same official screenshot illustrates two
steps or two manuals); each row is a separate file to download.
