raster PNG, fetched 2026-09-07 from Wikimedia Commons (the
`upload.wikimedia.org` thumb of the named Commons file, 500px wide — the
nearest Wikimedia-standard width to the 512px used previously):

Replacements from the previous CC0 simple-icons monochrome vectors (PDFs,
tinted at render time) to these full-color official logos. These raster
PNGs replace the vector PDFs and the per-glyph brand tint
(`glyphTintHex`); the imagesets intentionally no longer set
`preserves-vector-representation`.

Logos are trademarks of their owners; used to LAUNCH the respective apps,
not to imply affiliation.

Note: `imo` has no imageset — Commons hosts no official IMO logo and
simple-icons removed it over trademark concerns, so it keeps the SF
Symbol stand-in.
