## Description
Add the "Medicine times" mapping section to the medication settings: three slot rows (morning / afternoon / evening) with time controls, a reset-to-defaults action, and validation failure lines; any spoken rendering of the times goes through the SpokenTime formatter (NFR-MSR-004 — no raw interpolation). `saveMedicationSlotClock(_:)` (IF-9) validates first, persists through the C1 store, then runs `rearmForSlotClockChange()` (T-010) and returns a `SlotClockSaveResult` whose lines surface the re-arm report honestly (rearmed / kept / unresolvedSlots / persistenceFailed — m-1). Add the one-shot retime-refused note (m-5) on the `appointmentSmsNoteDismissed` precedent: coordinator `@Published` state, dismiss action, persisted key via the SettingsPersistence allow-list (precedent key and sites: `AppCoordinator.swift` :1145–1151, :3030, :11736; consumption pattern at `LeafViews.swift` :197), shown until dismissed once, then never again. Wire the scheduler hooks at composition: `onSignificantEvent` to the calendar write path (T-015), `onSlotEntryRetimeRefused` to the note.

```gherkin
    And the note is never shown again

  Scenario: A refused retime surfaces the note once
    Given a slot entry whose retime is refused
    When the refusal hook fires
    Then the one-shot note appears
    And dismissing it persists the dismissal
```
