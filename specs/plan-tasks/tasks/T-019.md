## Owned files

- Extends `ios/ElderlyAssistantTests/App/L10nCatalogCoverageTests.swift` with the instruction family checks (key reservation only; usage-disclosure assertions are T-020's).

## Description
Add the complete instruction copy family in both languages, verbatim from the design table. The copy is elder-facing plain language: no codes, no filenames, no technical instructions. Placeholder counts must match, and the Nepali values must be real translations rather than copied English.

## Acceptance criteria

```gherkin
Feature: Instruction localisation catalogue

  Scenario: Every instruction key resolves in both languages
    Given the 36 instruction keys from the design table
    When the catalogue is checked
    Then every key has an English value and a Nepali value
    And no Nepali value is blank or byte-identical to its English value
    And no key outside the reserved family is added

  Scenario: Placeholder counts match between languages
    Given a key that carries a count or time placeholder
    When both values are inspected
    Then the placeholder names and counts are identical
    And the formatted time path uses instruction.atTimeFormat

  Scenario: Behaviour-bearing copy is present and exact
    Given instruction.reminderUnavailable and instruction.foregroundNote
    When the catalogue is inspected
    Then both resolve in both languages
    And the English copy matches the design verbatim

  Scenario: The family is contiguous and alphabetically placed
    Given the instruction key prefix
    When the catalogue order is inspected
    Then the keys form one contiguous block
    And existing families are untouched
```

## Implementation notes
- Follow design §10.3 (the 36 keys with exact English and Nepali copy), §11.3 N (localisation gates), §11.3 O.
- Copy the strings exactly. Do not paraphrase, do not shorten, do not add exclamation marks or emoji, do not add error numbers.
- `instruction.reminderUnavailable` and `instruction.foregroundNote` are behaviour-bearing; a missing key is a visible defect, not a cosmetic gap.
- Insert the family as one alphabetical contiguous block, matching the house tests for neighbouring families. Do not reorder or retranslate existing keys.
- This unit reserves only the app copy. Camera and microphone usage descriptions (`Info.plist` and `InfoPlist.strings`) belong to T-020, even though they are also localised.
- Do not change the Xcode project; `Localizable.xcstrings` is already a declared resource.
- No source file references these keys yet. That is expected: catalogue entries are inert until later units use them, and the coverage checks are scoped to the family.
