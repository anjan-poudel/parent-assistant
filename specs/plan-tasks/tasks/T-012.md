## Description
Add every new user-visible key in both shipped languages (ne + en), as static key families: the acknowledgement and clarification copy (owner's forms only — "did you mean X" / "X or Y"; no leading questions, no numbered lists, ever), the walk prompts and ended lines, the evidence capture lines (including the D11 announce that names the bound medication), the settings mapping section, the editor slot/quantity/meal controls, the one-shot retime note, the two new family alert bodies (`intakeRecorded`, `escalationStarted`), the calendar significant-event copy, and the new error lines (`medication_slot_unresolved` surface line, editor error keys). **Apply the M-1 copy amendment** to the calendar-sharing consent disclosure in both locales — the pinned strings from design-l2's review-l1 resolutions section, which state that safety alerts (a missed dose, a possible double dose, or a dose that needs attention) are always shared with every family contact who has an email; the ne string repairs the shipped `परिवारलाई परिवारलाई` duplication in the same edit. `calendarShare.consent.body` is unchanged. No key embeds a clock time; times are interpolated through SpokenTime at the rendering site (T-020).
