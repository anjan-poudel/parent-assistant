## Owned files

- Extends `ios/ElderlyAssistantTests/Services/Instructions/InstructionCaptureTests.swift` with adapter contract and source-pin cases.

## Description
Implement the two production capture surfaces behind the coordinator's protocols. The library picker must be `PHPickerViewController` in video mode, which needs no photo-library permission. The recorder must use `UIImagePickerController` in video mode with camera and microphone capture, capped at 180 seconds, and hand the chosen file to the store's staged-copy callback rather than copying it itself.

## Acceptance criteria

```gherkin

  Scenario: The library picker asks for no permission
    Given the picker adapter is presented
    When the person chooses a video

  Scenario: The recorder caps recording at the configured duration

    When recording runs
    Then the platform video maximum duration is 180
    And the camera and microphone are the only media types
    And no photo-library mode is used

  Scenario: Dismissing the picker or recorder reports cancellation
    Given the picker or recorder is presented
    When the person cancels
    Then the completion receives cancelled
    And no staged copy is attempted
    And the coordinator returns to idle

  Scenario: A failed staged copy is reported, not swallowed
    Given the store callback cannot create the staged file
    When the picker returns a chosen video
    Then the completion receives writeFailed with the storage cause
    And no accepted video is produced

  Scenario: The source file is never opened from a temporary UI-owned URL after dismissal
    Given the platform hands a URL that is valid only for the callback
    When staging runs
    Then the bytes are copied during the callback
    And no URL is retained after the completion returns
```

## Implementation notes
- Follow design §2.4 (C04 adapters), §10.1 (camera and microphone purpose strings are T-020's), §11.3 J, §11.3 P (source hygiene).
- `PHPickerViewController` with a videos filter is the only library path. It is permission-free by design and must remain so. Do not add `NSPhotoLibraryUsageDescription`.
- `UIImagePickerController` with `sourceType = .camera`, `mediaTypes = [movie]`, `cameraCaptureMode = .video`, `videoMaximumDuration = 180` and `videoQualityType = .typeHigh` (or the configured equivalent). The microphone is captured by the camera session; T-006 checks authorization before this adapter appears.
- The adapter receives a `makeStagedCopy` callback and calls it with the callback-scoped URL while the callback is still valid. It must not retain that URL.
- Keep all UIKit/PhotosUI imports inside `#if os(iOS)`. The file lives under `App/`, which T-026 adds to the release-gate feature roots.
- No autoplay, preview player, trimming, compression, transcode, upload or share sheet.
