# T-011: Routine entry instruction delta and the strict store read

## Metadata
- **Group:** TG-04 — Routine and event owner seams

## Owned files
- Extends `ios/ElderlyAssistant/Services/Reminders/RoutineEntry.swift` with the optional `instruction` field and tolerant decoding.
- Extends `ios/ElderlyAssistant/Services/Reminders/RoutineStore.swift` with `loadEntriesIfReadable()`.
- Extends `ios/ElderlyAssistantTests/Services/Reminders/RoutineEntryTests.swift`.
- Extends `ios/ElderlyAssistantTests/Services/Reminders/RoutineStoreTests.swift`.

## Description
Make the routine owner able to carry a zero-or-one instruction without breaking any stored payload, and add the strict read that the orphan sweep needs. `loadEntriesIfReadable()` returns nil on every read failure, including a first-run missing key, while the legacy `loadEntries()` keeps returning an empty array for every existing caller. This unit is the sole owner of must-carry finding **M-4**.

## Implementation notes
- **M-4 (review-l2 Condition):** `RoutineStore.loadEntriesIfReadable() -> [RoutineEntry]?` is nil on **any** `storage.read` failure, including the first-run absent key. Do not special-case "missing" as empty. `RoutineScheduler.entriesIfReadable()` (T-013) delegates to it. The legacy `loadEntries()` and its `[]` contract stay untouched.
- Tolerant decode: `instruction = try? container.decodeIfPresent(Instruction.self, forKey: .instruction)`. A malformed nested instruction must not take down the whole routine list; it decodes as nil.
- The raw kind is preserved exactly. Must-carry **B-2:** a stored text instruction round-trips as `"text"`, never as a numeric case or a renamed value.
- `instruction` defaults to nil and the memberwise initializer keeps source compatibility for existing call sites. Do not add a required parameter.
- Do not add media teardown, scheduling, notification or observability code here. T-013 owns `entry(deleting:)` and the write seam.
- The strict read is the only new read API. Do not change existing read caching or add a second key.
