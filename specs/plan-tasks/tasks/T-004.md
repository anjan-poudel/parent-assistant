## Description
Define the playback boundary the views use and implement the AVKit adapter behind it. The adapter owns the platform player, preflight, ready observation, failure observation and teardown; it owns no timers, no copy and no policy about when playback may start.

## Acceptance criteria

```gherkin
Feature: Instruction video playback adapter

  Scenario: Playback never starts on presentation
    Given a video instruction on screen
    When the card, cover or editor appears
    Then no player is created and no audio session is activated
    And playback begins only after the person activates the play control

  Scenario: Preflight failure reports one plain failure and stays closed
    Given a URL that is missing or not playable
    When preflight runs
    Then the adapter emits failed with unsupported or playerFailed
    And no player is presented
    And no retry loop or network fetch is attempted

  Scenario: Dismiss pauses before releasing
    Given the player is presenting and playing
    When dismiss is called
    Then playback is paused first
    And the player and item are released after the pause
    And no event is emitted after dismiss returns

  Scenario: A late event after close is ignored
    Given the adapter has been dismissed
    When the platform delivers a ready or finished observation
    Then no event reaches the caller
```

## Implementation notes
- Follow design §2.7 (C07), §3.4 (event and failure enums), §6.3 (event catalogue), §8.2 (IO discipline), §11.3 I (playback cases).
- `InstructionPlaybackEvent` is exactly `.preflightPassed`, `.ready`, `.failed(InstructionPlaybackFailure)`, `.finished`, `.closed`.
- The adapter may use `AVPlayerItem` KVO and `AVPlayerItemFailedToPlayToEndTime` notifications. It must not implement a ready timer; that belongs to T-017's controller (must-carry ownership separation).
- URLs are callback-scoped: use the URL passed to `present` for the lifetime of that call and do not cache it on the adapter or in a singleton.
- Keep the AVKit import inside `#if os(iOS)` if that matches the surrounding codebase style. The protocol and event types must compile on every platform the target builds for.
- Do not add the controller, observability emission, copy keys, autoplay or a replay path. Replay is a fresh `present` from the view.
- No transcode, compression, trimming, streaming or network access is permitted anywhere in this path.
