## Description
Create the pure dose-line composer: given the structured quantity (`MedicationQuantity` value + unit from T-001), `DoseLine.compose` produces the single human-readable dose line stored on the entry (`doseDescription` replacement path used at save by T-017). Composition is localized through the catalog keys T-012 defines (unit labels in ne and en, singular/plural handled by the composer), deterministic, and free of any clock time — the meal relation is context rendered elsewhere, never a second time.

## Acceptance criteria

```gherkin
Feature: Structured quantity composes into one dose line

  Scenario: The family states how much and the line composes
    Given a stored quantity of 2 with a known dose unit
    When the dose line is composed
    Then the line renders the value and the localized unit label
    And composing the same quantity again yields the identical line (deterministic)

  Scenario: No quantity means no dose line (edge)
    Given an entry saved without a quantity
    When the dose line is composed
    Then the composer returns no line
    And nothing is invented or inferred
```

## Implementation notes
- Pure function; no I/O, no state, no date handling. Callable from the editor save path without a view.
- Unit labels come only from the T-012 catalog keys (W0, already landed); no hardcoded user-visible string in this file.
- The composer never writes to storage; persistence is T-017's save gate.
