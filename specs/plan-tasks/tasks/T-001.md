## Description
Land the value layer every later unit compiles against: the three instruction kinds with raw `String` storage, the wire model with tolerant decoding, the write algebra values, the single-owner identity and root rules, the bounded filename parser, the configuration defaults, and the AVFoundation probing/inspecting seam with the import error taxonomy. Nothing here performs IO beyond the two inspection methods, and nothing here knows about stores, views or notifications.

## Acceptance criteria

```gherkin
Feature: Instruction value model and inspection seam

  Scenario: A text instruction round-trips and reports presence
    Given an Instruction with kind "text" and non-blank text
    When the value is encoded and decoded again
    Then kind remains the raw string "text"
    And isPresent is true
    And no media fields are invented

  Scenario: Malformed or legacy-shaped payloads never throw away the owner
    Given a stored entry whose instruction object has unknown or missing optional fields
    When the model is decoded
    Then decoding succeeds and unknown fields are ignored
    And a missing kind or blank text yields isPresent false rather than a decode failure

  Scenario: Video inspection rejects an unplayable or over-long source
    Given a source file with no video track or a rounded duration above 180 seconds
    When inspection runs
    Then the result is the matching InstructionImportError case
    And no bytes are copied and no file is created
```

## Implementation notes
- Follow design §3.4 (declarations), §3.5 (payload/write algebra), §4.1–4.3 (wire shape and owners), §4.4 (tolerant decode table), §9.1 (defaults).
- `Instruction.kind` stays a raw `String`, not the enum. `InstructionPayload` carries the validated `InstructionKind`. This is must-carry **B-2** groundwork: stored text instructions keep the exact raw value `"text"`.
- Defaults: `maxDurationSeconds` 180 (inclusive; a rounded 180 is accepted), `maxBytes` 209_715_200, `validationTimeoutSeconds` 20, `orphanGraceSeconds` 60, `recordingQuality` `.high`, `stagingChunkBytes` 1_048_576.
- The filename guard (must-carry **N-1**, **N-4**) must reject an empty name, any name that is not a single plain path component, and any name that resolves outside the owner root. Reuse the validation in the image stores rather than inventing a second rule.
- Event roots use `ev-` plus lowercase 32-byte SHA-256 hex of the event identifier (design §4.3).
- `InstructionVideoInspecting.swift` also declares `InstructionImportError` (seven cases exactly as design §3.3). Keep the AVFoundation types internal and free of app state.
- Do not add `InstructionDraft`, `InstructionPendingMedia` or `InstructionCommit` in this unit; T-003 adds them to `Instruction.swift` once the store's accepted-video value exists.
- Do not add observability, copy keys, stores or views.
