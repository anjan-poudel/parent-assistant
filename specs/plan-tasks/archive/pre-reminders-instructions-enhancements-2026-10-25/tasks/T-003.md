## Description
Extend `MedicationEntry` with `quantity` (T-001 types), `slot` and `mealRelation`, all optional with memberwise defaults and `decodeIfPresent` in the custom decoder so every legacy payload still loads (pre-purpose, pre-slot). `scheduleTimes` stays as the resolved-time mirror (D2) — never an arming input. **Fix the trap:** `withScheduleTimes` (:144) must copy the complete value (rebuild via a full-field copy or a `var copy = self` assignment) so quantity/slot/mealRelation survive every copy path, including `setScheduleTimes` (:152). Extend `MedicationAdherenceLog` with `evidencePhotoFileName: String?` (decodeIfPresent; legacy logs load) and append `intakeRecorded` and `escalationStarted` to `FamilyAlertType` — appended only, so existing wire raw values never renumber.

## Acceptance criteria

```gherkin
Feature: The entry surface is quantity + slot + meal relation, legacy-safe

  Scenario: Family saves an entry in the new model
    Given the medication editor for a household
    When the family enters a medication name, a quantity, the morning slot and the before-meal relation and saves
    Then the entry is persisted with its quantity, slot and meal relation
    And the family was never required to enter a clock time

  Scenario: Legacy payloads load unchanged
    Given an entry payload written before this feature (no quantity, no slot, no meal relation, no purpose)
    When the payload is decoded
    Then the entry loads with nil new fields and its stored times intact
    And no migration rewrites the stored payload

  Scenario: A slot entry survives the schedule-times copy (failure guard)
    Given a slot entry with quantity, slot and meal relation set
    When the entry is copied through the withScheduleTimes path
    Then the copy still carries its slot, meal relation and quantity
    And nothing is silently dropped

  Scenario: The alert taxonomy is appended, not renumbered (edge)
    Given the shipped wire raw values of every FamilyAlertType case
    When the two new cases are added
    Then every shipped raw value is unchanged
```
