## What was built

`DialogueManager.swift` (design-l2 §8, C-MTC-01):

- **`ProbeKind`** (`.slotFill` / `.candidateChoice`, String raw) and
  **`DialogueSlot`** (Phase 1: `.musicQuery` only).
- **`DialogueCandidate`** — id / labelKey / domain / query / appID / matchKeys.
- **`DialogueFrame`** — id, probeKind, slot, domain, activeCommand, candidates,
  defaultQuery, sourceTranscript, `var` attempts, `var` deadline; the half-open
  `isExpired(at:)` (`now >= deadline`); two factories: `slotFill(...)` (records
  the pending command verbatim; placeholder `.distantPast` deadline — `arm` is
  the only live writer) and `candidateChoice(...)` (no domain, no pending
  command — nothing executes unasked).
- **`DialogueFrameResolution`** — the closed ten-case set of §26/L2-D16:
  `.answered(DialogueMerge)`, `.defaultExecuted`, `.candidateSelected(index:)`,
  `.exhausted`, `.cancelled`, `.escaped`, `.bargedIn`, `.timedOut`,
  `.superseded`, `.emergency`.
- **`DialogueError`** — closed `Equatable` vocabulary: `.windowBusy`,
  `.noResolution`, `.catalogUnavailable` (thrown by the T-126 loader),
  `.emptyMerge`.
- **`DialogueConfig`** — `maxProbes` 2, `maxCandidates` 3, `maxSlotOptions` 4.
- **`DialogueManager`** — main-queue-confined (no locks, no actors): `arm`
  (window-busy guard first and expiry-aware, then the no-resolution guard; on
  success stores the draft with `attempts = 1` and
  `deadline = now() + answerWindowSeconds`); `liveFrame` (expiry-aware read —
  an expired frame is dropped, the next utterance is a fresh command);
  `noteAttempt()` (attempts += 1 on the same frame identity, deadline
  restamped from the later reading, L2-D6; absent/expired → 0, no-op);
  `resolve(_:)` (the single idempotent funnel — clears and returns the frame
  for every outcome in the closed set).
- **C-1 / review-l2 F-1 resolved by construction.** The answer window is an
  injected constructor parameter (`init(answerWindowSeconds:now:)`); the file
  never addresses `VoiceSessionStateMachine.Config.confirmationTimeoutSeconds`
  at the type level (instance `var` at `App/VoiceSessionStateMachine.swift:95`)
  and contains no window literal — 45 s stays single-source at the machine,
  and the coordinator (T-136) passes the instance value in. The clock is
  injected too, so deadline boundaries are tested without wall-clock waits.
- **`DialogueProbeComposer.probeText(for:catalog:retry:locale:)`** —
  template-only (FR-MTC-016 / NFR-MTC-009; no model consult, no generated
  text): `slotFill` = the group's `questionKey` with `%@` = at most
  `maxSlotOptions` option labels plus the any-option label joined `", "`, or
  `dialogue.probe.musicAny` verbatim when no group claims the pending query (or
  no catalog — the degraded L2-D12 path); `candidateChoice` =
  `dialogue.understood.no` + one space + `dialogue.didYouMean` with `%@` = at
  most `maxCandidates` candidate labels; a candidate label's own `%@` fills
  from its `query`, falling back to the primary match key (the user's own
  word); `retry: true` prefixes `dialogue.retry` with exactly one space. All
  copy resolves through `L10n.str(key, locale:)` against the T-129 keys.
- **Log safety by construction.** No console output, no observability
  metadata, no network, no telemetry in either new file — the coordinator's
  funnel emits the closed-vocabulary events instead. The hoisted block lives
  inside `DialogueManager.swift` (not a fifth source file) precisely so
  T-138's four-entry FEATURE_ROOTS log-gate wiring stays exhaustive.
