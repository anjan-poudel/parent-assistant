## Open items / deviations

1. **The S3 scaffold strip is frame-kind aware — the design-internal V13
   conflict resolved (the one red-run root cause).** Design-l2 §22 pins V13
   (`candidateChoice; "युट्युब"` ⇒ `.candidatePick(.optionName)`) while the
   same section's preamble pins the strip vocabulary as
   `isMusicScaffoldToken ∨ probeEchoWords`, and
   `isMusicScaffoldToken("युट्युब") == true` by this repo's shipped
   implementation (`युट्युब` is in `musicDevanagariContainmentDrops` — the
   extractor drops the trigger morpheme as a query component). Applying the
   request vocabulary on a candidateChoice frame strips the elder's own
   matchKey word, made V13 unreachable (red run: `.invalid(.emptyAfterStrip)`
   where the pin demands `.candidatePick`), and would equally kill the
   candidate pick for any other drop-word matchKey.
   Resolution: the pinned public `stripScaffold(_:)` keeps its signature and
   full vocabulary (the REQUEST reading — slotFill V3/V5/V6 unchanged); the
   ladder and `merge` use the same helper with the frame's reading —
   candidateChoice strips probe-echo words only (§22 S3's own parenthetical
   for that axis). Pinned by an explicit assertion in the V13 test
   (`stripScaffold("युट्युब") == ""` while the candidate pick still fires).
   No catalog/route/rule file was touched; the pinned helper's public
   behaviour is unchanged.
2. **Ladder order implemented per design (L2-D1), not the task summary's
   splash order.** The task file's Implementation-notes splash line orders
   "escape → cancel/amendment → B1–B7"; design-l2 L2-D1/§9 and the C5 summary
   pin barge-in BEFORE cancel/amendment, with the counterexample "होइन, मेरो
   छोरालाई फोन गर". Implemented as designed (escape → barge-in →
   cancel/amendment); pinned by `testNegationPlusStrongCommandBargesInNotMerges`
   and the V10/V11 rows.
3. **C1 bound read as strictly above `InputSanitiser.maxLength`.** L2-D5 +
   V14 ("`InputSanitiser` would clamp — the check runs first"): the gate is
   `raw.count > maxLength`, i.e. at exactly the bound the answer is valid and
   never truncated (sanitise only clamps above the bound, so no prefix risk).
   The Gherkin's "at or above the raw length bound" is looser wording; the
   boundary is pinned both ways in the V14 test (200 → valid free text,
   untruncated; 201+ → `.invalid(.overLength)`).
4. **S4's catalog tables use strict whole-value token equality**, deliberately
   stricter than `DialogueOptionCatalog.option(matchingWholeValue:in:)`
   (containment): V3 needs "दुर्गा भजन बजाऊ"'s stripped value to capture the
   repetition, not the option name, and V11 needs "दुर्गा होइन" to stay free
   text. The catalog API and its pinned tests are untouched; the rationale is
   documented at the matcher.
5. **`classify` gains an additive defaulted `medicationNames: [String] = []`.**
   Design §9's pinned signature has no medication vocabulary while `isBargeIn`
   requires it (B1) and §12.2's call site computes it. The default keeps the
   pinned six-argument call shape compiling unchanged, **but with the default
   the medication-photo half of B6 is inert** (B1, the static acknowledgement
   predicate, does not read the parameter) — the router's interception site
   (T-136) must pass the live vocabulary. Corrected at the W2 review (F-1/F-2).
6. **Closed invalid for unreachable index addressing.** A bare index word
   beyond the offered options/candidates — and any index word when no catalog
   can address the frame (degraded E3) — is `.invalid(.emptyAfterStrip)`, the
   M-5 closed-outcome reading (never an out-of-range pick, never merged as
   free text). Pinned in the totality test.
7. **`merge` mirrors classify's degenerate reading**: a marker-only
   value throws `.emptyMerge` (classify reports `.invalid(.degenerateAnswer)`)
   — classify and merge can never disagree on resolvability. SlotFill shipped
   with the gate; candidateChoice gained the same gate at the W2 review (F-3;
   post-review addendum below).
8. **S5 anyPlay matching checks both value readings** against the localized
   `dialogue.option.anyPlay` label and the pinned aliases (canonical and
   scaffold-stripped), because the en label's stripped form ("just anything")
   is covered by no alias; copy ships verbatim from design-l2 §16 (owner copy
   review at feature review).
9. Nothing else outstanding in this unit.
